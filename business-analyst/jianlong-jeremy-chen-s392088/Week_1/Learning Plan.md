# PRT681 / PRT585 - Business Analyst (BA) 3-Week Learning Plan

> **Strategy & Goal:** 
> * **Focus:** Practical skills over heavy theory (Breadth over Depth).
> * **Objective:** Master core BA deliverables (BRD, BPMN, User Stories, SQL queries) to support team sprint releases and satisfy unit requirements.

---

## Week 1: Foundations, Market Research & Tooling
**Focus:** Understanding the BA role, core methodologies, and essential productivity tools.

### Daily Action Items
* **Day 1: Unit & Role Familiarization**
  * Review Week 1 requirements on OneNote and GitHub guidelines.
  * Conduct market research on Seek/LinkedIn for BA role requirements.
* **Day 2: BA Core Concepts (LinkedIn Learning)**
  * Complete modules on *Problem/Vision Statements* & *Current/Future State*.
  * Understand the *Requirements Value Chain*: Business Goal -> Code.
* **Day 3: Environment & Collaboration Tools Setup**
  * Set up Jira, Confluence, Draw.io/Visio, and Git/GitHub.
  * Connect with team members on Teams/Slack.
* **Day 4: Tool Notes Preparation (4-Line Structure)**
  * Write Tool Notes for Jira, Confluence, Draw.io, and SQL.
  * Document: *What it is*, *Why used*, *Common use cases*, *Simple example*.
* **Day 5: Timesheet & Progress Submission**
  * Log 6 individual hours in `S226 PRT681 Timesheets.xlsx`.
  * Upload Week 1 learning plan and notes to GitHub.

### Week 1 Key Deliverable
* Completed **Skills & Resources Table** + **3-Week Learning Plan** submitted to GitHub.

---

## Week 2: Process Modelling, BRD Drafting & User Stories
**Focus:** Converting raw business ideas into structured documentation and diagrams.

### Daily Action Items
* **Day 1: As-Is & To-Be Process Mapping (BPMN)**
  * Practice drawing swim lane diagrams using Draw.io/Lucid chart.
  * Map out the current **As-Is** workflow and design the optimized **To-Be** workflow.
* **Day 2: Business Requirements Document (BRD) Drafting**
  * Define Project Scope (*In-Scope* vs. *Out-of-Scope*).
  * Document Functional and Non-Functional Requirements (NFRs).
* **Day 3: User Story Writing & INVEST Principle**
  * Break down system features into User Stories: `"As a... I want to... So that..."`.
  * Apply **INVEST** criteria (*Independent, Negotiable, Valuable, Estimable, Small, Testable*).
* **Day 4: Acceptance Criteria (AC) & BDD**
  * Write `Given-When-Then` scenarios for key user stories.
  * Align AC with QA testers for test case coverage.
* **Day 5: Grooming & Review**
  * Conduct Backlog Grooming / Requirement Walkthrough with Dev and QA teams.
  * Update Week 2 Timesheet (6 Hours).

### Week 2 Key Deliverable
* Drafted **BRD/PRD** and a set of **Jira User Stories** with Acceptance Criteria.

---

## Week 3: Data Validation, Agile Board & UAT Testing
**Focus:** Hands-on data verification, agile tracking, and user acceptance testing.

### Daily Action Items
* **Day 1: SQL Basics for BA Data Validation**
  * Learn basic SQL queries (`SELECT`, `WHERE`, `JOIN`, `GROUP BY`).
  * Practice verifying database entries against UI submission forms.
* **Day 2: Agile Board & Backlog Management in Jira**
  * Organize user stories in Jira backlog, set priorities, and assign story points.
  * Structure Sprint 1 tasks and dependencies.
* **Day 3: UAT (User Acceptance Testing) Execution**
  * Draft UAT test scripts based on Acceptance Criteria.
  * Perform UAT testing on developed features and log bugs/defects in Jira.
* **Day 4: Documentation Refinement & Release Notes**
  * Prepare User Guide / Release Notes for stakeholders.
  * Finalize Traceability Matrix: Business Goal -> User Story -> Test Case.
* **Day 5: Portfolio & Unit Finalization**
  * Review all weekly deliverables against OneNote checklist.
  * Complete Week 3 Timesheet logging and push final work to GitHub.

### Week 3 Key Deliverable
* Fully groomed **Jira Backlog**, **UAT Test Plan**, and completed **Project Handover Document**.
