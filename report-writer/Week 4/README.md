I created Sales_Performance_Dashboard.xlsx, a complete Excel reporting project you can either use as a portfolio piece or use your own data. Since you didn't specify a topic, I took a sales-reporting project. I did not open the finalized in Excel, but it did recalculate, with 0 formula errors and dashboard totals tie to the raw data.

What is included :
The instructions include purpose, guide to sheets, how to use, and assumptions.
The dashboard is displaying six KPIs (revenue, profit, margin, orders, average order value and units), insights generated automatically and four charts. There is a dropdown for region selection (see yellow cell, C4). This filters the KPIs, insights, monthly chart, product chart and category table. The views region and salesperson always show all regions.
The monthly trend summary and the region / product / category / salesperson vs target summary. All in conditional formatting.
Four hundred sample orders. The blue columns are the user input and black columns are formula (region, category, price, cost, revenue, profit, month). Validation using dropdowns is done for salesperson and product columns.
Lists would have prices and costs, salesperson targets, regions and the reporting start month. Any modifications will reflect updates.

Information about the project: 
The numbers are fabricated sample data, not actual figures. Substitute your own orders in blue input columns on Data and copy the formulas down. Rows 2 to 2000 are covered in the summary ranges.
This tool employs classic functions (SUMIFS, INDEX/MATCH, EDATE) which are compatible with any version of Excel.
