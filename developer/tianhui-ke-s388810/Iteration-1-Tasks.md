Notes below follow the "three lines per topic/sub-topic" instruction. Each tool was studied via the assigned LinkedIn Learning / YouTube course before writing notes.

## 1. JIRA (Cloud Edition)
- Cloud-based tool for tracking tasks, bugs, and sprints using boards (Scrum/Kanban) and issue types (Epic, Story, Task, Bug).
- Projects are organised into backlogs and sprints; each issue can be assigned, prioritised, labelled, and linked to others.
- Basic administration covers creating projects, configuring workflows/permissions, and managing users and issue schemes.

## 2. Confluence
- Team wiki/knowledge-base tool used for documentation, meeting notes, and requirement specs, organised into Spaces and Pages.
- Pages support templates, tables, macros, and can be linked directly to Jira issues for traceability.
- Search and page history make it useful for keeping a single source of truth that survives staff turnover.

## 3. Visio
- Diagramming tool for flowcharts, org charts, network diagrams, and BPMN-style process maps using drag-and-drop shapes.
- Shapes can carry data fields, and diagrams can be linked to Excel data for automatic updates.
- Essential training covered stencils, connectors, layers, and exporting diagrams to PDF/Word for reports.

## 4. Draw.io / diagrams.net
- Free browser-based alternative to Visio, integrates with Google Drive, Confluence, and GitHub for version-controlled diagrams.
- Supports flowcharts, wireframes, and BPMN with the same connector/shape logic as Visio.
- Useful for quick collaborative diagramming without a paid licence.

## 5. Trello
- Kanban-board tool using boards, lists, and cards to track work visually (To Do / In Progress / Done).
- Cards support checklists, due dates, labels, and attachments; Power-Ups extend functionality (e.g., calendar view).
- Lightweight alternative to Jira, good for small teams or personal task tracking.

## 6. Microsoft Planner
- Task-management tool integrated with Microsoft 365, organising tasks into Buckets on a Kanban-style board.
- Tasks can have due dates, priority, attachments, and checklists, and sync with Outlook/Teams.
- Simpler than Jira but tightly integrated with the Microsoft ecosystem the team already uses.

## 7. OneNote
- Digital notebook organised into Notebooks > Sections > Pages, used for free-form notes, screenshots, and tables.
- Supports tagging (To Do, Important), audio recording, and real-time co-authoring across devices.
- This course notebook itself is a OneNote notebook — read-only sections are used to publish task instructions to the team.

## 8. Microsoft Office Suite (365)
- Cloud-connected version of Word/Excel/PowerPoint/Outlook with auto-save, version history, and real-time co-authoring.
- "Getting Started" covered app navigation and OneDrive integration; "Working Smarter" covered shortcuts, templates, and Focus tools.
- Files are accessed the same way across desktop, web, and mobile via a Microsoft 365 account.

## 9. Outlook & Teams
- Outlook manages email, calendar, and contacts, with rules, categories, and shared calendars for team scheduling.
- Teams provides chat, channels, video meetings, and file sharing, and integrates directly with SharePoint/OneDrive.
- Together they form the day-to-day communication layer used for standups and stakeholder updates.

## 10. Git, GitHub & Bitbucket
- Git is a distributed version control system tracking changes via commits, branches, and merges on a local repo.
- GitHub hosts remote repos and adds pull requests, issues, and Actions (CI/CD) on top of Git.
- Bitbucket is functionally similar to GitHub (same underlying Git commands) but with a different web UI, often paired with Jira/Confluence (all from Atlassian).

## 11. SharePoint & OneDrive
- SharePoint hosts team sites, document libraries, and (as used here) OneNote notebooks with permission-controlled access.
- OneDrive is personal cloud storage that syncs files across devices and integrates with SharePoint libraries.
- Both are bundled into the Microsoft 365 subscription already covered above.

## 12. Power BI
- Business intelligence tool for building interactive dashboards from data sources like Excel, SQL Server, or CSV.
- Power BI Desktop is used to model data (relationships, DAX measures) and design report visuals before publishing to the Power BI Service.
- PL-300 path covers the certification track: data prep, modelling, visualisation, and deployment/governance.

## 13. Lucidchart
- Cloud diagramming tool similar to draw.io, focused on flowcharts, ER diagrams, and wireframes with real-time collaboration.
- Templates and a large shape library make it fast to produce professional-looking diagrams.
- Advanced features include conditional formatting and data-linked diagrams for larger technical documents.

## 14. Microsoft Forms
- Simple survey/quiz tool for collecting structured responses, with built-in charts for quick analysis.
- Forms can branch based on answers and export results directly to Excel.
- Useful for lightweight stakeholder surveys or team retrospectives.

## 15. Excel
- Spreadsheet tool for tabular data, calculations, and pivot tables/charts; core skill for both BA and Report Analyst work.
- Advanced formulas (VLOOKUP/XLOOKUP, INDEX-MATCH, IF, SUMIFS) and PivotTables are the main tools for analysis.
- Covered as part of the Microsoft 365 bundle above rather than a separate course.

## 16. Notepad++
- Lightweight text/code editor with syntax highlighting for many languages, used for quick edits without a full IDE.
- Supports plugins, multi-file search/replace, and macros for repetitive text edits.
- Useful for viewing/editing config files, logs, or scripts on Windows machines.

## 17. PowerShell
- Command-line shell and scripting language for Windows administration (files, processes, services, registry).
- Uses cmdlets (Verb-Noun pattern, e.g. `Get-Process`) and supports piping objects (not just text) between commands.
- PowerShell Core is the cross-platform version that also runs on Linux/macOS.

## 18. Batch Script
- Older Windows scripting language (`.bat` files) for automating simple command-line tasks.
- Common commands: `echo`, `set`, `if`, `for`, `call` for looping/conditionals and calling other scripts.
- Largely superseded by PowerShell for anything beyond very simple automation, but still common in legacy environments.
